The editor also runs in this tab

Not a demo and not a cut-down rewrite. It is the same Kotlin that builds the Windows, macOS, Linux and Android apps, compiled to WebAssembly and drawing through the same renderer — so the screens are not lookalikes of the app, they are the app.

This one is a preview, and here is exactly why. It is built and it loads, but on the machine it was built on — a server with no graphics card — the renderer draws shapes correctly and then fails on anything with text in it. That may well be the software rasteriser rather than the build, since a stock three-line Compose page fails there in exactly the same way. It has not yet been watched working on a real graphics card. So: try it, and if the page comes up blank, that is the bug and not your machine — the installers above go nowhere near a browser.

What runs

All of it. Java and Bedrock screens on the design canvas, with the same drag, resize, rotate, marquee and snapping. The paint app, with layers, blend modes, the scribble magic eraser and shape recognition. Every export: resource packs, the project file, HTML + CSS, React, SwiftUI, Flutter and Android XML.

What a browser does differently

A page cannot write to your disk, so Save is a download and Open is a file picker — and an export of more than one file arrives as a zip rather than as fourteen separate downloads. Your document is kept in the tab itself, so closing it and coming back finds the design where you left it.

What it needs

A browser with WebAssembly garbage collection — Chrome or Edge 119+, Firefox 120+, Safari 18.4+ — and working hardware acceleration, since it draws through WebGL. The page checks for the first before it downloads anything, and says so if a graphics context never arrives. The first visit fetches about twelve megabytes; after that it is cached.

Three targets

Each one drawn in its own widget language

A card is not a themed surface with a name printed on it. New in 2.2.0

A paint canvas, with a magic eraser you can see working

Layers, blend modes, pressure-aware brushes, symmetry, flood fill and a tile-based undo history — plus two things worth showing rather than listing.

Scribble across it, not at it

A tap could only ever take one colour, which is useless on a real object — a face is a dozen colours, a leaf is a gradient. Scribble across the thing and everything the scribble touches goes with it.

The rainbow trail is not decoration. Nothing is removed until you lift your fingerpointerfinger, so without it the gesture would be invisible: you scribble, see nothing, let go, and something vanishes. It runs through the whole hue circle so it cannot be camouflaged by whatever is underneath it.

Draw a shape by drawing it

Rough box becomes a rectangle. Even sides become a square. Three corners become a triangle. A loop becomes a circle, or an ellipse if it was squashed. Drawn at an angle, it stays at that angle.

A scribble it cannot read is left exactly as drawn — which matters more than the recognition does. Quietly replacing your drawing with a confidently wrong triangle is the worse failure.

The short version

What it is, who it is for, how to use it

What this is

A visual editor for interfaces. Blockbench does 3D models for Minecraft and Blender does 3D for everything else; UILabs is the equivalent for the flat side — menus, HUDs, inventories, forms and panels — in Minecraft and, through its code exports, well beyond it.

Who it is for

Mod developers, app developers and UI designers who would rather place a panel than count pixels in a JSON file. You lay the screen out by hand and it writes the format the target actually reads, so the tedious half is done and the design half is yours.

How to use it

Pick an edition. Drag components onto the canvas, nudge them with the arrow keys, and group what repeats into a prefab. When it looks right, Export writes a resource pack, a project file, or source in the language your target speaks.

Everything is saved on your device — no account, no upload, no telemetry.

First launch

What your OS will say, and why

UILabs is not signed with a paid commercial certificate, so each platform warns about it once. None of these warnings mean anything is wrong with the file.

macOS — “cannot be opened because the developer cannot be verified”

The .dmg is not signed with an Apple Developer certificate, so Gatekeeper blocks the first launch. Open it once with right-click → Open and choose Open, or clear the quarantine flag:

xattr -dr com.apple.quarantine "/Applications/UILabs.app"

Every launch after the first is normal.

Windows — SmartScreen says the publisher is unknown

Choose More info → Run anyway. Removing that warning needs a paid code-signing certificate from a commercial CA, which this project does not have.

Android — Play Protect offers to scan the APK

That prompt appears for anything installed outside the Play Store, whatever it is signed with. The only thing that removes it is publishing on Play itself.

Upgrading is a normal install over the top; the release APK carries the same signing key across versions, so it updates in place rather than asking you to uninstall first.
