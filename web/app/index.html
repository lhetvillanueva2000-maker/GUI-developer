Loading the editor. It is a few megabytes of WebAssembly, and only on the first visit — after that your browser has it cached.

This browser could not start the editor. It needs WebAssembly with garbage collection, which means Chrome or Edge 119+, Firefox 120+, or Safari 18.4+. The desktop and Android builds have no such requirement — see the downloads.

The editor started but is not drawing. It renders through WebGL, and some machines cannot give a browser tab a working graphics context — a very old GPU, a driver the browser has blocklisted, or hardware acceleration switched off in the browser's settings. Turning hardware acceleration back on usually fixes it. Failing that, the desktop and Android builds do not go through the browser at all: see the downloads.
